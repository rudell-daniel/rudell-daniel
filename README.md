## 🔐 Featured Cybersecurity Projects

### Authenticated vs. Unauthenticated Vulnerability Assessment

**Tenable Vulnerability Management | Microsoft Azure | Windows 11 | Ubuntu Linux**

Compared authenticated and unauthenticated vulnerability assessments across
Windows and Linux virtual machines to evaluate credential validation,
privilege levels, host-level visibility, and assessment coverage.

**Project Highlights**

- Windows: 46 unauthenticated findings vs. 79 authenticated findings
- Linux: 22 unauthenticated vs. 57 standard-user vs. 61 root-authenticated findings
- Validated credential status before interpreting assessment results
- Evaluated how Linux privilege levels affected assessment depth
